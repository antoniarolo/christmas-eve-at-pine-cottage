# Christmas Eve at Pine Cottage

An interactive winter world for the Digital Marketing take-home exam. Visitors can trim a Christmas tree, switch on its lights, add a star, light the fireplace, watch snow fall, and unwrap a hot cocoa recipe.

Tap an ornament to hang it. Tap a gold dot to add another of the same kind, or select a placed ornament to take it down. The cottage saves your decorations and settings in your browser.

## Run locally

Open `index.html` in a browser. The site uses HTML, CSS, JavaScript, and original SVG artwork. It needs no installation or build step.

## Play online

[Visit Christmas Eve at Pine Cottage](https://antoniarolo.github.io/christmas-eve-at-pine-cottage/)

Start in the snowy pine grove. Swing the axe three times, carry the tree to the cottage, and set it in its stand before decorating. Use **Start Christmas Eve over** to replay the journey.
